## 🚀 Featured Projects

### 🗓️ [University Exam Scheduling System](https://github.com/reva-32/timetable_system)
> Python • Flask • MongoDB • Graph Algorithms

- Building a conflict-free university examination scheduling system for practical use within my college.
- Uses DSATUR-based graph coloring for Course → Slot allocation, greedy room allocation for Course → Room, and constraint-based teacher assignment for Room → Teacher.
- Allows teachers to adjust assigned duties based on their preferences while helping coordinators generate and manage examination timetables.
- 🚧 Currently under development and being refined in discussion with college faculty.

### 🛡️ [DevGuard CLI](https://github.com/reva-32/devguard-cli) · [![PyPI](https://img.shields.io/badge/PyPI-v1.0.1-3776AB?style=flat-square&logo=pypi&logoColor=white)](https://pypi.org/project/devguard-cli/1.0.1/)
> Python • PyPI • CLI Security Tool

- Open-source secret scanning CLI that detects exposed credentials using regex pattern matching and Shannon entropy analysis.
- Supports manual and pre-commit scanning with configurable detection rules, allowlists, and file-level scanning.
- Generates developer-facing reports and detailed local audit logs, keeping sensitive secret information within the system.

### 💳 [Razorpay Payment Recovery Engine — Resurrect](https://github.com/reva-32/Resurrect)
> Node.js • Express • MongoDB • Razorpay • Gemini

- Automated payment recovery platform that analyzes failed payments and recommends the most appropriate recovery action instead of blindly retrying.
- Provides interactive chatbot-based insights and visual analytics to explain failure reasons, prioritize payments, and determine whether to retry, send an SMS reminder, or create a fresh payment link.
- Deployed with Vercel, Render, and MongoDB, using synthetic data alongside a live demo flow.

### 📦 [MSME 360] · `In Development`
> React • Node.js • Express • MongoDB • AI
